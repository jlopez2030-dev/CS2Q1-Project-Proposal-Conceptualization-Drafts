# Project Title Multi-tool Study App 

## Project Description 
This is a Python program that helps students when studying especially in the aspect of unit conversion and helpful when students are in need of a study timer.

## Features

(Features) Example below:
- Enter given units and desired units
- calculate the answer (desired unit)
- Enter amount of time
- program will time it and will tell you when it is over


## How to Run the Program

(Requirements to Run) Example below:

1. Make sure you have Python installed.
2. Download the file `study_tool.py`.
3. Open a terminal or command prompt.
4. Run the program by pressing F5 or clicking 'Run' 
5. Follow the on-screen instructions to enter given unit,desired unit and/or the time.

## Example Output
(Output). Example below:
Do you want to use the unit conversion? (yes/no) : yes

Enter given unit: 60 seconds
Enter desired unit: minute

The answer is: 1 minute

Do you want to use the built-in timer? (yes/no): yes

Enter time: 1:00

Timer ends: now
